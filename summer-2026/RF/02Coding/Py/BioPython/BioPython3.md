# Lab 3: Sequence Properties

This lab goes from simple calculations (GC content) to complex analysis
such as protein properties. The 8 parts to this lab are:
### Part 1: GC Content
- Calculate percentage of G and C bases

Try predicting the results first before running the program - e.g. the GC content of DNA sequences.

### Part 2: Molecular Weight
- Calculate MW for DNA, RNA, and proteins
  Try changing the sequences - simpler ones or more complicated ones.

### Part 3: Reverse Complement
- Essential for understanding DNA directionality

### Part 4: Translation
- Convert DNA → RNA → Protein using genetic code
See if you can figure out why some translations result in "early" stop codons.

### Part 5: ORF Finding
- Identify potential coding regions

### Part 6: Codon Usage
- Analyze which codons are used

### Part 7: Protein Analysis
- Detailed biochemical properties

### Part 8: Sequence Comparison
- Calculate similarity between sequences
